# Conceptual scientific illustrations

These eight transparent illustrations depict generic cells, proteins, molecules,
assay equipment, simulation concepts, laboratory automation, source records and
computational models. They support explanatory navigation and schematic objects
on the website. They are conceptual artwork, not observed images, identified
structures, experimental results or evidence of a model's architecture.

The illustrations were generated with the built-in image tool on 26 October
2026 at the author's request. Its backend version was not exposed. Scientific
labels, arrows, quantities and diagram layouts remain separate native objects.
The manuscript uses its own source-derived/native figure artwork.

`ScientificIcon.astro` creates appropriately sized WebP delivery variants from
these retained PNG masters. Tables and source-derived scientific graphics have
their own sources and interpretation boundaries.
