# Conceptual scientific illustrations

These eight transparent illustrations depict generic cells, proteins, molecules,
assay equipment, simulation concepts, laboratory automation, source records and
computational models. They support explanatory navigation and schematic objects
on the website. They are conceptual artwork, not observed images, identified
structures, experimental results or evidence of a model's architecture.

The illustrations were generated with the built-in image tool on 26 October
2026 at the author's request. Its backend version was not exposed. Scientific
labels, arrows, quantities and diagram layouts remain separate native objects.
The manuscript uses its own source-derived/native figure artwork.

`ScientificIcon.astro` creates appropriately sized WebP delivery variants from
these retained PNG masters. Tables and source-derived scientific graphics have
their own sources and interpretation boundaries.

## Evidence journey panorama

`evidence-journey-v2.png` is a conceptual panorama generated with the built-in image
tool on 6 November 2026. It depicts a generic cell, protein, assay equipment,
automation and evidence dossier. The backend version was not exposed. It is not
an identified structure, assay measurement, simulation trajectory or experimental
result. Labels, navigation and animation state remain native website elements.
The PNG is the retained master; Astro produces responsive WebP delivery variants.

## Record, validation and evidence-package illustrations

`target-identity-record-v3.png`, `orthogonal-validation-v3.png` and
`candidate-evidence-v3.png` were generated with the built-in image tool on
7 November 2026. Its backend version was not exposed. These transparent
illustrations represent an identity record, complementary assay equipment and
an evidence dossier. Their decorative internal marks are not measured data,
verified biological structures, validated assays or approved candidate outcomes.
They remain separate image objects in the editable report schematics; scientific
labels, relationships and required evidence are native text and connectors.
