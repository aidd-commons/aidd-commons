## 运行之前

**模式：对已提交声明做可运行的枚举。** 该命令用 RDKit 把三个已声明空间的每一个产物都构建出来，
并用四个靶分子逐一测试。**这里没有任何分子是设计提案**，也没有任何空间是真实的筛选库。

```bash
python labs/design_space/inspect_space.py show
```

候选空间总是以"规模"被引用。**输入决定它有多少，构造决定什么是可达的。**
而通常只有前者被报出来。

## 1. 三种构造

| 空间 | 名义规模 | 构造 |
| --- | --- | --- |
| `enumeration` | 25 | 一个固定核心、两个连接点、短列表 |
| `enumeration_grown` | 100 | **同一个核心**、更长的列表 |
| `scaffold_hop` | 25 | **不同的核心**、原来的列表 |

每一个规模都是由输入列表的乘积**重新算出来的**，而不是从声明的数字里读出来的；
并且每一个产物都被真正构建，以确认这个空间没有悄悄小于它的输入。

## 2. 把空间涨到四倍，只多够到一个分子

| 靶分子 | `enumeration` | `enumeration_grown` | `scaffold_hop` |
| --- | --- | --- | --- |
| `t1` 原核心、短列表取代基 | 是 | 是 | 否 |
| `t2` 原核心、仅长列表取代基 | 否 | **是** | 否 |
| `t3` 吡啶核心，差一个原子 | 否 | **否** | 是 |
| `t4` 磺酰胺连接子 | 否 | **否** | 否 |

从 25 涨到 100，够到了 `t2`。它让 `t3` 与 `t4` **和之前完全一样地不可达。**

`t3` 与一个可达分子之间**只差环上的一个原子**。
它在两个枚举空间里**在任何列表规模下都不可达**，
因为核心被构造固定住了，而**再多的取代基也买不到一个新核心。**

## 3. 两个规模相同的空间可以互不相交

`scaffold_hop` 与 `enumeration` 名义规模相同：同样的列表、25 个产物。
它够得到 `t3`，而两个枚举空间在任何规模下都够不到。

它同时**一个也够不到**它们所覆盖的东西。第三个空间与被放大的空间**没有任何共同成员**，
并有一项检查要求这一点。

**所以可达性上的差别不是规模上的差别，一个更大的数字也并不包含一个更小的。**

## 4. 有一个靶分子哪儿都够不到

`t4` 把连接子从酰胺换成磺酰胺，在这三种构造里**一个都够不到**。

**这是关于这三种构造的陈述，而不是关于别的任何东西的陈述。**
第四种构造会够到它，同时会够不到这三种覆盖的某些东西。
**这里没有任何一个空间可以代表"化学"。**

```bash
python labs/design_space/inspect_space.py check
```

共十三项检查，包括每个名义规模都是其输入列表的乘积、
被放大的空间共享同一个核心（因此只有输入变了）、
以及第三个空间的差别在于构造而不在于规模。

## 5. 可达性不是什么

**可达的意思是：这个构造能把这个分子写下来。**
它完全没有说这个分子能不能被做出来、是否稳定、或者是否值得做。

**一个空间是一台生成器，不是一份计划。**
[生成闸门](/zh-cn/labs/generation-gate/)从另一侧记录了同一条边界——它把路线可行性保持为未评估；
而[断键比较](/zh-cn/labs/retro-disconnection/)展示了"回收一条路线"确立了什么、又没确立什么。

## 独立练习

一份平台推介说："我们的组合库覆盖 100 亿个可合成化合物，比任何筛选库都高出几个数量级。"

请说出这个数字告诉了你什么、又没告诉你什么，并给出一个能让它变得有信息量的问题。

<details data-worked-answer>
<summary>参考答案：区分枚举数量与化学覆盖</summary>

试剂列表长度的乘积计算的是声明构造下的可能组合，并不直接等于不同有效产物、实际可取得的化合物或经实验验证的合成数量。增加试剂可能产生新产物；新结构多样性的大小需要测量，不能从乘积变大直接推出。

先问被比较的筛选集合是实物库存、按需制备，还是自身也由枚举产生。可以比较这些库存，但必须说明计数对象，并使用相容的可获得性定义。

骨架多样性是结构覆盖的一种有用视角，不是化学空间的完整定义；同一骨架内的不同结构仍可能具有不同性质。在本构造实验中，将一个空间扩大四倍只多达到一个声明目标，另一个仍不可达。这是关于这些具体构造与目标的证据。

应问库中有多少不同有效产物与骨架组，以及该构造能达到哪些声明的目标结构，然后检查合成主张的依据。巨大的枚举计数本身既不能回答可达性，也不能回答实验可行性。

</details>

## 它不做什么

它枚举已声明的构造并报告每一个够到什么。它不确立任何分子能被做出来、
不确立任何空间值得搜索，也不确立这三种构造代表了"一个空间可以被建构的方式"。

这些分子与列表是为教学撰写的。相关论证见
[流与约束搜索](/zh-cn/learn/molecular-generation/flows-and-constrained-search/)
