## 运行之前

**模式：对一份构造记录做可运行的检查。** 该命令读取一份已提交的 JSON，并用 RDKit 做子结构匹配。
**这里没有任何结果是真的**、没有化合物被测试过，**本实验中的任何东西都不是对任何物质的安全性评估。**

```bash
python labs/safety_evidence/inspect_safety.py show
```

一份毒性档案把五种不同的证据打印在同一列里，于是它们被读成同一条"坏的程度"的渐变。
**它们是用五种不同方式得到的，也会在五件不同的事情上出错。**

## 1. 记录里从不存警报

文件存的是**需要做实验才能得到的发现**：测定结果、器官毒性、整体动物观察。
**警报每次都从结构现算，一处也不存。**

这就是全部的设计决定。**把警报存在测量结果旁边，正是本实验所针对的那次坍缩**；
所以有一项检查会拒绝这样做的记录，并有一个 known-bad 测试真的去做一遍，以证明该检查会开火。

## 2. 大多数触发警报的化合物从未被测量

**12 个里有 7 个**至少匹配一条警报。**其中 5 个完全没有任何被测量的发现。**

**它们的全部安全性记录就是一次模式匹配。没有人跑过任何东西。**
而在档案页上，那一列看起来和旁边那一列一模一样，后者装的是结果。

有一个化合物匹配了**两条**警报，却不带任何发现。**警报数上去了，证据没有。**

## 3. 各层彼此不一致，而其中两种不一致并不是同一回事

| 情形 | 化合物 |
| --- | --- |
| 警报响了，测量说是阴性 | `c01` |
| 警报响了，没有人测过任何东西 | `c03` `c04` `c05` `c06` `c07` |
| 没有警报，却有阳性发现 | `c08` `c09` |

最后一行杀掉了那个让人安心的方向：**没有警报什么也预测不了。**
两个结构档案"干净"的化合物带着阳性发现。

前两行在报告上看着一样，实际完全不一样。
**一条被测量推翻的警报，是被检验过并且输了；一条没人核过的警报，根本没有被检验。**
**把它们打印成同一个样子，正是警报得以保有它从未赢得的权威的方式。**

## 4. 没有剂量语境，这些都不构成风险陈述

**7 个测定结果里有 2 个不带浓度**，因此无法与带浓度的那些相比较；
而记录下来的浓度之间相差四倍。

**记录里任何地方都没有声明暴露量**，而文件写明了这为什么要紧，
不是把这个缺口留成沉默的。**200 微摩尔下的阳性与 1 微摩尔下的阳性，
在档案页上读起来一样，含义则完全不同。**

## 5. 真正能了结问题的那一层，恰恰几乎没有

**12 个里只有 1 个**带有任何整体动物层面的证据。

**这是安全性记录的常态，而不是这一份的缺陷。**
警报是免费的，测定是便宜的，动物是昂贵的——**而档案页给这三者同样大的版面。**

```bash
python labs/safety_evidence/inspect_safety.py check
```

共十四项检查。**一份无法被读成五个分开层级的记录，根本不会被汇总**——
因为对一份已经坍缩的记录做汇总，正是本实验所警告的那件事。

## 独立练习

一张候选物评审幻灯片写着："该化合物有两条结构警报和一个阳性 hERG 信号。
建议降级，转而推进备选系列，那个系列是干净的。"

请说明这句话的每一半各自依赖什么，并说出会改变这个决定的那**一个**问题。

<details data-worked-answer>
<summary>参考答案：在匹配暴露与覆盖下比较证据</summary>

两条结构警报识别的是计算得到的子结构匹配，是关于表征的证据，不是毒性测量。多个警报可能指向同一个结构特征，因此警报数不是独立危害数。上面的构造示例包含触发警报、却没有记录到发现的化合物；这不说明该化合物安全。

所述 hERG 信号需要测定格式、浓度响应证据、质量对照及其与相关暴露的关系。100 微摩尔与 1 微摩尔下的信号不能仅因都称为阳性而视为等价。幻灯片本身既不能确立有效测量，也不能确立其对预定用途的影响。

备选系列被称为干净，也需要同样的核查。未触发警报、未观察到发现和未进行测量是不同状态。排序之前，应比较两个系列已测终点、浓度、暴露裕度及缺失结果。

应问备选系列相对先导系列测了哪些终点、在什么浓度和对照下测量。测试较少可以解释发现较少，但不能据此认定本例就是这个原因。匹配证据可能保留、削弱或逆转原排序，并不保证一定逆转。

</details>

## 它不做什么

它什么也不评估。这里没有化合物被测试过、没有结果是真的，
也不能从这份文件里得出关于任何物质的任何陈述。

它也不是说警报没用。**一条警报是一次便宜的"该去看看"的提示，
而"去看"正是另外四层在做的事。** 失败在于：
**把"该去看看"的提示，打印在"看过之后的结果"的同一列里。**
