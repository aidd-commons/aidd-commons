## 运行之前

先阅读[筛选阳性率与迁移](/zh-cn/learn/dti-screening/screening-prevalence-and-transfer/)。完成后，你应能把类别标签追溯到阈值，区分未测试的诱饵与已观察的非活性物，并检查筛选主张在算术上是否成立。

**模式：在构造数据上的可运行演示。** 该命令读取一份已提交的 JSON，并用 RDKit 算骨架。
**不拟合任何模型**、没有化合物被测定过，这里也没有任何东西是筛选提案。

```bash
python labs/binder_definition/inspect_definition.py show
```

一份结合物数据集看上去像是关于化学的事实。**它多半是一摞决定。**
本实验把分子固定住，只挪动那些决定。

## 1. 文件里不存类别

十二个教学化合物带着构造的终点数值，十二个教学诱饵不带数值。**没有任何一条带类别标签。** 教学文件中的 `measured` 字段代表情景中接受测定的一组，其数值不是实验测量。

这是刻意的。**类别是由一次选择产生的**，存下标签就会把产生它的那次选择藏起来；
并有一个测试断言该文件不含标签字段。

## 2. 阈值是某个人挑的一个数

| 阈值 | 阳性数 |
| --- | --- |
| 5.0 | 9 |
| 5.5 | 8 |
| 6.0 | 6 |
| 6.5 | 4 |
| 7.0 | 4 |

同样十二个构造化合物与数值，在阈值变化时产生不同的阳性计数，没有增加新观察。类别标签必须附带阈值及其科学依据。

## 3. 四个标签落在不确定度带内

构造终点声明的不确定度带是 0.3。在主阈值 6.0 处：

- `m03` 数值为 6.1，**距阈值 0.1**，被归为阳性
- `m04` 数值为 5.9，**距阈值 0.1**，被归为阴性
- `m06` 数值为 6.0，**正好压在线上**，被归为阳性
- `m09` 数值为 5.8，**距阈值 0.2**，被归为阴性

这四个数值与阈值足够接近，声明的不确定度带内的变化就可能改变标签。这个带没有给出重复测量的分布，也不保证某个具体标签必然改变。应在阈值类别旁保留连续值和不确定度。

## 4. "阴性"其实是两种不同的东西

| 数据集 | 阳性 | 阴性 | 从未被测量 | 普遍率 |
| --- | --- | --- | --- | --- |
| 仅被测量的 | 6 | 6 | 0% | 0.500 |
| 加入诱饵 | 6 | 18 | **67%** | **0.250** |

在这个构造情景中，已测非活性类别代表声明的测定和阈值下的低读数；诱饵代表未测试、但被假定为非活性的分子。这份教学文件的两类分子都没有接受真实测定。

加入诱饵**没有改变任何一个阳性**，因为它没有增加任何测量。它把普遍率从 0.500 挪到了 0.250。
**随机选择器的期望精确率等于普遍率**，所以**任何被报出的精确率所要超过的那个数，
是被一个关于未测试分子的决定挪动的。**

被扩大的阴性类里有三分之二完全没有测量，**而"阴性"这个词把两种都罩住了，不加区分。**

## 5. 泛化单元不是分子

十二个分子塌缩成 **4** 个 Bemis-Murcko 骨架，其中三个骨架各带不止一个分子：

- 四个共享 `O=C(Nc1ccccc1)c1ccccc1`
- 三个共享 `c1ccc(-c2ccccn2)cc1`
- 三个共享 `c1ccc(N2CCNCC2)cc1`

在分子层面做随机划分，可能把同一骨架的成员放到两侧，留出的分子因而可能与训练分子十分接近。骨架计数描述这一规则下的分组，不代表已证明的独立单元。

有一个化合物 `m11` 是无环的，**根本没有骨架**。对它而言单元不是更粗，而是**未定义**；
实验把这件事报出来，而不是悄悄给它安一个。

**在主阈值处有六个阳性，坐落在三个骨架上。** 这是六个带标签分子和三个被覆盖的骨架组；任何一个计数都不能单独确立统计独立性或前瞻性泛化。

```bash
python labs/binder_definition/inspect_definition.py check
```

共十六项检查，包括诱饵是否不带任何测量、诱饵集是否写明了它所依赖的假设、
阈值是否在分析之前声明，以及声明的不确定度是否为正。这些是构造契约的检查，不是对实验噪声模型的验证。

## 独立练习

考虑一篇假想虚拟筛选论文中的构造主张："我们的模型在一个含 50 个活性物与 1,500 个诱饵的基准上达到 0.94 AUC，
并在前 1% 中回收了 40% 的活性物。"

先检查声明的回收量能否容纳在候选短名单中，再说明这些指标不能确立什么，并列出有助于解释基准的两个缺失计数。

<details data-worked-answer>
<summary>参考答案：先检查短名单，再解释指标</summary>

这条回收主张按原文计算不成立。共有 1,550 个化合物，1% 是 15.5 个；常规取整的短名单有 15 或 16 个位置，而 50 个活性物的 40% 是 20 个，无法放入该短名单。若纳入并列项后集合更大，或使用另一分母，必须明确说明；0.94 AUC 不能解决这个矛盾。

选定的 30 比 1 比例使阳性率约为 0.032，这是随机选择的期望精确率。ROC-AUC 的随机排序参照值则为 0.5，因为它比较阳性与阴性分数的次序。改变诱饵数量或组成可能改变富集与排序难度，但不会自动改善每一个指标。[scikit-learn 指标定义](https://scikit-learn.org/stable/modules/model_evaluation.html#roc-metrics)区分了 ROC 曲线、精确率与召回率。

未测试的诱饵不是已观察的非活性物。某些假定阴性可能有活性，但仅凭这条主张，既不知道其比例，也不知道指标偏差的方向。还需要测定、活性阈值、诱饵选择规则和划分信息。

两个有用的缺失计数是活性物中的不同骨架组数，以及阴性中经实验观察的非活性物数。还应检查回收的活性物如何分布在这些组上。骨架归属有助于诊断重叠，却不能把组数变成已证明的有效样本量。若没有已测非活性物，阴性标签仍是假设，不是已观察的阴性测定结果。

</details>

## 它不做什么

它不拟合模型、不报告任何性能，也不说哪种定义是正确的。
**诱饵集在其假设被写明时是一个正当的工具。**
本实验所针对的失败是：把诱饵与被测非活性放在同一个词下报告，并在两者的并集上引用一个指标。

这些分子与数值是为教学撰写的，**不是测量**。真实的冻结筛选协议见
[ChEMBL 契约检查](/zh-cn/labs/chembl-contract-inspection/)；
一个结果在不同测定语境之间会发生什么，见
[重复不等于迁移](/zh-cn/labs/screening-transport/)。

## 真实数据 ChEMBL 37 EGFR 结合体分类器与阴性类审计（`public-binders`）

在 `24` 个真实 ChEMBL 37 人类 EGFR（`CHEMBL203`）实测化合物（跨 `15` 个 Bemis-Murcko 骨架划分为 `16` 个训练与 `8` 个测试，主阈值 `pIC50 >= 7.0`，测定不确定度 `0.3` 对数单位）与 `8` 个性质匹配的未测试诱饵上拟合与评估 Morgan 指纹（`128` 位，`radius = 2`）加理化描述符逻辑回归结合体分类器（`alpha = 0.2`，`400` 步梯度下降）：

```bash
.venv/bin/python labs/binder_definition/inspect_definition.py public-binders
.venv/bin/python labs/binder_definition/inspect_definition.py check-public-binders
```

- **阈值网格与边界敏感性**：在 `{6.0, 6.5, 7.0, 7.5, 8.0}` 网格下的阳性数分别为 `18`、`14`、`12`、`9` 与 `4`，其中 `4` 个真实化合物（`CHEMBL1173655`、`CHEMBL24828`、`CHEMBL101253`、`CHEMBL365756`）落在主阈值 `7.0` 的 `0.3` 对数单位不确定度范围内。
- **不同阴性类定义下的留出测试集表现**：
  - `measured_inactives_only`（`4` 个活性物对 `4` 个实测非活性物，`prevalence = 0.5`，`never_measured_negative_share = 0.0`）：`roc_auc = 0.75`，`precision_at_0_5 = 0.6667`，`recall_at_0_5 = 1.0`，`false_positive_rate_at_0_5 = 0.5`。
  - `untested_decoys_only`（`4` 个活性物对 `8` 个未测试诱饵，`prevalence = 0.3333`，`never_measured_negative_share = 1.0`）：`roc_auc = 0.875`，`precision_at_0_5 = 0.8`，`recall_at_0_5 = 1.0`，`false_positive_rate_at_0_5 = 0.125`。
  - `pooled_measured_and_decoys`（`4` 个活性物对 `4` 个实测非活性物加 `8` 个未测试诱饵，`prevalence = 0.25`，`never_measured_negative_share = 0.6667`）：`roc_auc = 0.8333`，`precision_at_0_5 = 0.5714`，`recall_at_0_5 = 1.0`，`false_positive_rate_at_0_5 = 0.25`。
