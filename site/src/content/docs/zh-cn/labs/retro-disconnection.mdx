## 运行之前

**不训练也不执行任何模型**、不运行任何反应，这里也没有任何东西是合成提案。

```bash
python labs/retro_disconnection/inspect_disconnection.py compare
```

四类断键方法通常被压成一个回收率来比较。那个数字藏起了两件事：
**这些方法失败的成因彼此不同**；以及**回收到一条被记录的路线，完全说不出这条路线能不能被跑出来**。

## 1. 三类跑了，第四类说明了自己为什么不跑

`rule` 是人凭化学知识手写的变换。`template` 的出处是一份反应数据集而不是某个人。
`retrieval` 把产物查一遍，把记录在它名下的反应物返回。`learned` 则是**声明了但不运行**，
因为本仓库的离线实验里不执行任何模型。

**把它列出来正是重点所在。** 一个悄悄丢掉某一类的比较，
会让人以为比了四类而其实只比了三类；这条边界应当被打印出来，而不是靠读者推断。

## 2. 在先例集内部，三类都是满分

先例集既是检索可以查的东西，也是模板被抽取出来的地方。十条路线里有五条在其中。

在它内部，每一类都回收 5/5。**出了它，三者完全分开：**
规则 5/5，模板 3/5，检索 0/5。

这个分离来自构造集里一个刻意的选择：**先例集中不含任何 suzuki-biaryl 反应。**
检索错过它们，是因为那些分子不在它的表里；模板错过它们，
是因为数据集从未包含过那个类别、于是根本没有对应模板；
而手写规则覆盖了那个类别，只因为有人选择去写它。

**同一列分数，三种不同的成因。** 一个百分比分辨不出你面对的是哪一种，
而三者的修复动作完全不同：换数据、从更宽的数据集抽取、或者再写一条规则。

## 3. 同一个方法，两个分数，取决于一次划分

检索在先例集内的五条路线上回收 5/5，也就是 **100%**——那是一次查表在自己的表上成功。
在全部路线上它回收 5/10，也就是 **50%**。

两个数字都不算错。**报哪一个完全由划分决定，而记忆型的方法正是从"划分选得差"里获益最多的那个。**
一个在自己见过的分子上被评测的检索基线，会赢过一切，并且泛化不到任何地方。

## 4. 回收到一条路线，不等于做对了

十个产物里有三个，规则提出了**不止一条**断键。还原胺化有两条，其中一个联芳基也有两条。

回收的含义是被记录的那条路线**在提案之中**。它**不**意味着方法选中了它、把它排在第一，
或者更偏好它。一个提出很多断键的方法，是用很低的代价买到回收率的；
而一个只数回收率的比较，会为此奖励它。

```bash
python labs/retro_disconnection/inspect_disconnection.py check
```

共十三项检查。**一个解析不了的结构会在任何方法被施加之前就中止运行**，
因为在一个读都读不出来的集合上无法比较方法。

## 5. 上面任何分数都没有确立什么

路线集里记着 `laboratory_feasibility: not_assessed`。本实验没有检查试剂可得性、
保护基、条件相容性、选择性、规模或成本中的任何一项。

**路线回收是关于一次图编辑的陈述。可行性是关于一间实验室的陈述。**
一条回收到了被记录路线的断键，仍然可能需要一个没人卖的试剂、
一个没人加的保护基，或者一套会把分子其余部分毁掉的条件。
这与[生成闸门](/zh-cn/labs/generation-gate/)把结构过滤器称作代理、
并把 `route_feasibility` 保持为未评估，是同一条边界。

## 独立练习

一篇逆合成论文报告："我们的模型在 USPTO-50K 上达到 92% 的 top-1 路线回收率，
优于基于模板的方法的 87%。这表明学习到的断键已经可以用于生产级路线规划。"

请说出这个比较**没有**确立什么，并说出你会先要的那**一个**数字。

<details data-worked-answer>
<summary>参考答案：先确认评价任务，再解释差距</summary>

先确定所报回收率衡量什么。top-1 预测选择一个候选答案，但答案可能是单步反应、反应物集合或完整路线。与一条记录答案一致，既不能说明其他提案在化学上错误，也不能说明记录提案适于生产。基准名称本身不能解决任务定义。

对于 92% 与 87% 的比较，应检查两个方法是否使用相同的测试样例、预处理、可访问反应信息及成功规则。检查模板来源和最近邻检索基线，不预先认定任一方法只记住了训练集。强检索结果是相关比较对象，不是对另一个模型记忆比例的测量。

一个有用的后续得分，是在预先指定、相关变换组未出现在训练中的留出集上计算回收率，同时报告样本数与不确定性。这检验了另一种泛化问题，却不能单独确立对所有新目标或生产流程的帮助。

生产规划还需要材料、条件、选择性、规模与路线执行的证据。原回收率不衡量这些结果。在任务和匹配比较明确之前，该主张仍是所报基准得分，不能等同于生产就绪。

</details>

## 它不做什么

这条路径不运行反应、不评估任何真实的逆合成模型，也不确立任何路线可以被做出来。
这十条路线是为教学撰写的，因此这些计数教的是**比较的结构**，而不是任何已发表方法的行为。
