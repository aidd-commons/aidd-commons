四类断键方法通常被压成一个回收率来比较。那个数字藏起了两件事：
**这些方法失败的成因彼此不同**；以及**回收到一条被记录的路线，完全说不出这条路线能不能被跑出来**。

## 1. 三类跑了，第四类说明了自己为什么不跑

`rule` 是人凭化学知识手写的变换。`template` 的出处是一份反应数据集而不是某个人。
`retrieval` 把产物查一遍，把记录在它名下的反应物返回。`learned` 则是**声明了但不运行**，
因为本仓库的离线实验里不执行任何模型。

**把它列出来正是重点所在。** 一个悄悄丢掉某一类的比较，
会让人以为比了四类而其实只比了三类；这条边界应当被打印出来，而不是靠读者推断。

## 2. 在先例集内部，三类都是满分

先例集既是检索可以查的东西，也是模板被抽取出来的地方。十条路线里有五条在其中。

在它内部，每一类都回收 5/5。**出了它，三者完全分开：**
规则 5/5，模板 3/5，检索 0/5。

这个分离来自构造集里一个刻意的选择：**先例集中不含任何 suzuki-biaryl 反应。**
检索错过它们，是因为那些分子不在它的表里；模板错过它们，
是因为数据集从未包含过那个类别、于是根本没有对应模板；
而手写规则覆盖了那个类别，只因为有人选择去写它。

**同一列分数，三种不同的成因。** 一个百分比分辨不出你面对的是哪一种，
而三者的修复动作完全不同：换数据、从更宽的数据集抽取、或者再写一条规则。

## 3. 同一个方法，两个分数，取决于一次划分

检索在先例集内的五条路线上回收 5/5，也就是 **100%**——那是一次查表在自己的表上成功。
在全部路线上它回收 5/10，也就是 **50%**。

两个数字都不算错。**报哪一个完全由划分决定，而记忆型的方法正是从"划分选得差"里获益最多的那个。**
一个在自己见过的分子上被评测的检索基线，会赢过一切，并且泛化不到任何地方。

## 4. 回收到一条路线，不等于做对了

十个产物里有三个，规则提出了**不止一条**断键。还原胺化有两条，其中一个联芳基也有两条。

回收的含义是被记录的那条路线**在提案之中**。它**不**意味着方法选中了它、把它排在第一，
或者更偏好它。一个提出很多断键的方法，是用很低的代价买到回收率的；
而一个只数回收率的比较，会为此奖励它。

```bash
python labs/retro_disconnection/inspect_disconnection.py check
```

共十三项检查。**一个解析不了的结构会在任何方法被施加之前就中止运行**，
因为在一个读都读不出来的集合上无法比较方法。

## 5. 上面任何分数都没有确立什么

路线集里记着 `laboratory_feasibility: not_assessed`。本实验没有检查试剂可得性、
保护基、条件相容性、选择性、规模或成本中的任何一项。

**路线回收是关于一次图编辑的陈述。可行性是关于一间实验室的陈述。**
一条回收到了被记录路线的断键，仍然可能需要一个没人卖的试剂、
一个没人加的保护基，或者一套会把分子其余部分毁掉的条件。
这与[生成闸门](/zh-cn/labs/generation-gate/)把结构过滤器称作代理、
并把 `route_feasibility` 保持为未评估，是同一条边界。

  Suzuki-Miyaura 记录共享 `1` 个完全相同的吲唑-喹啉联芳基产物

  `5566` 行，Xantphos 失败）到 `0.9029`（第 `2091` 行，跨度 `0.9029`），且 `12` 条中有
  `9` 条流动记录包含内标 `1,3-diethylbenzene`（`CCc1cccc(CC)c1`），而 `12` 条中有 `3` 条
  极性反转孔板记录省略了该内标。同时，来自 Ahneman 等人（*Science* `2018`，
  `doi:10.1126/science.aar5169`，`1536` 孔板、`60.0` °C、DMSO 中反应 `16.0` h）的 `24`
  条 Buchwald-Hartwig HTE 记录显示：固定底物而改变配体、碱与异噁唑添加剂时，
  `Brc1cccnc1` 的产率跨度为 `0.00%` 至 `98.73%`（`n = 4`，跨度 `98.73%`），`Clc1cccnc1`
  为 `0.00%` 至 `68.77%`（`n = 3`，跨度 `68.77%`），`FC(F)(F)c1ccc(Cl)cc1` 为 `0.00%` 至
  `45.05%`（`n = 3`，跨度 `45.05%`），`COc1ccc(Cl)cc1` 为 `0.00%` 至 `44.14%`（`n = 6`，
  跨度 `44.14%`）。
- **USPTO 原子映射、键编辑与模板回收（`t14-atom-mapping-transformation-class`）**：
  来自 `MolecularAI/aizynthfinder`（`test_reactions_template.csv`）的 `3` 条 USPTO
  原子映射反应与抽取出的 `RetroTemplate` SMARTS（携带 `64` 字符哈希 `23f00a3c507e...`、
  `dadfa1075f08...` 与 `01ba54afaa6c...`，置信度分别为 `0.9425`、`0.9855` 与
  `0.9708`）。RDKit 执行可回收全部 `3`/`3` 组记录反应物，并将酰胺键编辑 `(8, 9)` 与
  芳基氯酰胺化键编辑 `(7, 8)` 区分开。将产物芳环碳原子映射编号 `:7` 与 `:18` 互换会使
  `bonds_formed` 从 `[(8, 9)]` 恶化为 `[(3, 7), (6, 18), (7, 19), (8, 9), (8, 18)]`，
  直观展示映射错误如何传播到抽取出的模板中。
- **多步路线树、选择性与安全门槛（`t14-retrosynthetic-disconnection` 与 `t14-route-feasibility-material-safety`）**：
  针对吖啶-硫脲目标分子 `Cc1ccc2nc3ccccc3c(Nc3ccc(NC(=S)Nc4ccccc4)cc3)c2c1` 的 `3` 棵

  `acridine_route_1`（`2` 步，深度 `2`）中未保护对苯二胺（`Nc1ccc(N)cc1`）的双芳基化陷阱，
  以及 `acridine_route_2`（`2` 步，深度 `2`）中自反应性 `4`-溴苯胺（`Nc1ccc(Br)cc1`）的
  自身偶联陷阱。对比 `linear_route.json`（`2` 步，深度 `2`，`3` 个在库叶节点）与
  `branched_route.json`（`4` 步，深度 `3`，`5` 个叶节点且其中 `O` 不在库）还能标记出
  芳基氢过氧化物基团（`OOc1...`）。在 USPTO 苯甲酰苯胺中间体
  `N#Cc1cccc(NC(=O)c2ccc(F)cc2)c1F` 上，酰氯酰化（`0` 个竞争芳基卤位点）与
  `Fc1c(Cl)cccc1C#N` 上的 Buchwald-Hartwig 酰胺化（`2` 个邻位活化卤素竞争位点）被明确区分。
- **正向条件建模与 HTE 反馈（`t14-forward-reaction-lab-feedback`）**：在 `24` 条

  `6` 个零产率化学失败孔（因强碱诱导异噁唑开环毒化催化剂导致的 `0.0%` 产率），模型在这些
  毒化条件上的平均预测产率会从 `7.47%` 虚高至 `36.37%`（偏高 `+28.90` 个百分点）。因此，
  反馈台账严格区分 `well A01`（条目 `49`，产率 `10.6578%`，内标正常 ->
  `update_model_productive`）、`well H12`（条目 `1601`，产率 `0.0%`，内标正常 ->
  `update_model_negative_chemical_failure`）以及 `well P24`（条目 `1613`，内标缺失 ->
  `quarantine_qc_fault_repeat_dispense`）。

## 独立练习

一篇逆合成论文报告："我们的模型在 USPTO-50K 上达到 92% 的 top-1 路线回收率，
优于基于模板的方法的 87%。这表明学习到的断键已经可以用于生产级路线规划。"

请说出这个比较**没有**确立什么，并说出你会先要的那**一个**数字。

<details data-worked-answer>
<summary>参考答案：先确认评价任务，再解释差距</summary>

先确定所报回收率衡量什么。top-1 预测选择一个候选答案，但答案可能是单步反应、反应物集合或完整路线。与一条记录答案一致，既不能说明其他提案在化学上错误，也不能说明记录提案适于生产。基准名称本身不能解决任务定义。

对于 92% 与 87% 的比较，应检查两个方法是否使用相同的测试样例、预处理、可访问反应信息及成功规则。检查模板来源和最近邻检索基线，不预先认定任一方法只记住了训练集。强检索结果是相关比较对象，不是对另一个模型记忆比例的测量。

一个有用的后续得分，是在预先指定、相关变换组未出现在训练中的留出集上计算回收率，同时报告样本数与不确定性。这检验了另一种泛化问题，却不能单独确立对所有新目标或生产流程的帮助。

生产规划还需要材料、条件、选择性、规模与路线执行的证据。原回收率不衡量这些结果。在任务和匹配比较明确之前，该主张仍是所报基准得分，不能等同于生产就绪。

</details>

## 它不做什么

这条路径不运行反应、不评估任何真实的逆合成模型，也不确立任何路线可以被做出来。
这十条路线是为教学撰写的，因此这些计数教的是**比较的结构**，而不是任何已发表方法的行为。
