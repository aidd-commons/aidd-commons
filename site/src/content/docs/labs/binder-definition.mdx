## Before you run

Read [screening prevalence and transfer](/learn/dti-screening/screening-prevalence-and-transfer/) first. By the end, you should be able to trace a class label to its cutoff, distinguish an untested decoy from an observed inactive, and check whether a screening claim is arithmetically possible.

**Mode: runnable demonstration on constructed data.** The command reads one
committed JSON file and uses RDKit for scaffolds. **No model is fitted**, no
compound was assayed, and nothing here is a screening proposal.

```bash
python labs/binder_definition/inspect_definition.py show
```

A binder dataset looks like a fact about chemistry. It is mostly a stack of
decisions. This lab holds the molecules fixed and moves the decisions.

## 1. The file stores no classes

Twelve authored compounds carry constructed endpoint values. Twelve authored
decoys carry none. **Nothing carries a class label.** The field named
`measured` in the teaching file represents the assayed arm of the scenario;
its values were not measured in an experiment.

That is deliberate. A class is produced by a choice, so a stored label would hide
the choice that made it, and a test asserts the file has no label field.

## 2. The cutoff is a number somebody picked

| cutoff | positives |
| --- | --- |
| 5.0 | 9 |
| 5.5 | 8 |
| 6.0 | 6 |
| 6.5 | 4 |
| 7.0 | 4 |

The same twelve constructed compounds and values yield different positive
counts when the cutoff changes. No new observation is added. The cutoff and
its scientific rationale must accompany the class labels.

## 3. Four labels lie within the uncertainty band

The constructed endpoint declares an uncertainty band of 0.3. At the primary
cutoff of 6.0:

- `m03` has value 6.1, **0.1 from the cutoff**, filed as positive
- `m04` has value 5.9, **0.1 from the cutoff**, filed as negative
- `m06` has value 6.0, **exactly on it**, filed as positive
- `m09` has value 5.8, **0.2 from the cutoff**, filed as negative

These four values are close enough to the cutoff for a change within the
declared band to alter a label. The band does not specify a repeat-measurement
distribution or guarantee that any particular label would change. Keep the
continuous value and uncertainty alongside the thresholded class.

## 4. A negative is two different things

| dataset | positives | negatives | never measured | prevalence |
| --- | --- | --- | --- | --- |
| measured only | 6 | 6 | 0% | 0.500 |
| with decoys | 6 | 18 | **67%** | **0.250** |

In this constructed scenario, the assayed-inactive category represents a low
result under a declared assay and cutoff. A decoy instead represents an untested
molecule assumed to be inactive. No real assay was performed for either category
in this teaching file.

Adding decoys **changed no positive**, because it added no measurement. It moved
prevalence from 0.500 to 0.250. Expected precision of a random selector equals prevalence,
so **the number any reported precision has to beat was moved by a decision about
untested molecules.**

Two thirds of the enlarged negative class carries no measurement at all, and the
word "negatives" covers both kinds without distinction.

## 5. The generalization unit is not the molecule

Twelve molecules collapse to **four** Bemis-Murcko scaffolds, three of which
carry more than one molecule:

- four share `O=C(Nc1ccccc1)c1ccccc1`
- three share `c1ccc(-c2ccccn2)cc1`
- three share `c1ccc(N2CCNCC2)cc1`

A random split over molecules can put members of the same scaffold on both
sides. A held-out molecule may then resemble a training molecule closely. The
scaffold counts describe grouping under this rule, not proven independent units.

One compound, `m11`, is acyclic and has **no scaffold at all**. The unit is not
coarser for it, it is undefined, and the lab reports that rather than quietly
assigning one.

**At the primary cutoff there are six positives on three scaffolds.** Those are
six labelled molecules and three represented scaffold groups. Neither count
alone establishes statistical independence or prospective generalization.

```bash
python labs/binder_definition/inspect_definition.py check
```

Sixteen checks run, including that decoys carry no measurement, that the decoy
assumption is stated, that the cutoff was declared before the analysis, and that
the declared uncertainty is positive. These are checks on the constructed
contract, not validation of an experimental noise model.

## Independent exercise

Consider this constructed claim from a hypothetical virtual-screening paper: "our model achieves 0.94 AUC on a benchmark of
50 actives and 1,500 decoys, and recovers 40% of actives in the top 1%."

First check whether the stated recovery fits inside the shortlist. Then say
what the metrics cannot establish, and name two missing counts that would help
interpret the benchmark.

<details data-worked-answer>
<summary>Worked answer: check the shortlist before the metric</summary>

The recovery claim is inconsistent as written. There are 1,550 compounds, and
1% is 15.5 compounds. An ordinary rounded shortlist has 15 or 16 places, while
40% of 50 actives is 20 actives. That does not fit. A larger tie-inclusive set
or a different denominator would need to be stated explicitly; the reported
0.94 AUC cannot resolve this contradiction.

The selected 30-to-1 ratio gives a prevalence of about 0.032. This is the
expected precision of random selection. ROC-AUC has a different random-ranking
reference, 0.5, because it compares positive-negative score orderings. Changing
the number or composition of decoys can change enrichment and ranking difficulty,
but it does not automatically improve every metric. The
[scikit-learn metric definitions](https://scikit-learn.org/stable/modules/model_evaluation.html#roc-metrics)
distinguish the ROC curve from precision and recall.

An untested decoy is not an observed inactive. Some assumed negatives could be
active, but neither their frequency nor the direction of metric bias is known
from this claim. The assay, activity cutoff, decoy-selection rule and split must
be supplied.

Two useful missing counts are the distinct scaffold groups among the actives
and the experimentally observed inactives among the negatives. Also inspect how
the recovered actives are distributed over those groups. Scaffold membership
helps diagnose overlap; it does not turn a group count into a proven effective
sample size. If there are no measured inactives, the negative labels remain
assumptions rather than observed negative assay results.

</details>

## What this does not do

It fits no model, reports no performance, and does not say which definitions are
correct. A decoy set is a legitimate tool when its assumption is stated. The
failure this lab is built against is reporting decoys and measured inactives under
one word and quoting a metric over the union.

The molecules and values were authored for teaching and are not measurements. For
a real frozen screening protocol see the
[ChEMBL contract inspection](/labs/chembl-contract-inspection/), and for what a
result does when it moves between assay contexts see
[repeating is not transporting](/labs/screening-transport/).

## Real-data ChEMBL 37 EGFR binder classifier and negative-class audit (`public-binders`)

To fit and evaluate a real Morgan-fingerprint (`128` bits, `radius = 2`) + physicochemical logistic binder classifier (`alpha = 0.2`, `400` gradient steps) across `24` real ChEMBL 37 human EGFR (`CHEMBL203`) measured compounds (`16` train, `8` test across `15` Bemis-Murcko scaffolds, primary cutoff `pIC50 >= 7.0`, assay uncertainty `0.3` log units) and `8` property-matched untested decoys:

```bash
.venv/bin/python labs/binder_definition/inspect_definition.py public-binders
.venv/bin/python labs/binder_definition/inspect_definition.py check-public-binders
```

- **Cutoff grid and borderline sensitivity**: Positive counts across `{6.0, 6.5, 7.0, 7.5, 8.0}` are `18`, `14`, `12`, `9`, and `4`, with `4` real compounds (`CHEMBL1173655`, `CHEMBL24828`, `CHEMBL101253`, `CHEMBL365756`) sitting within `0.3` log units of the `7.0` primary cutoff.
- **Held-out test performance across negative-class definitions**:
  - `measured_inactives_only` (`4` actives vs `4` measured inactives, `prevalence = 0.5`, `never_measured_negative_share = 0.0`): `roc_auc = 0.75`, `precision_at_0_5 = 0.6667`, `recall_at_0_5 = 1.0`, `false_positive_rate_at_0_5 = 0.5`.
  - `untested_decoys_only` (`4` actives vs `8` untested decoys, `prevalence = 0.3333`, `never_measured_negative_share = 1.0`): `roc_auc = 0.875`, `precision_at_0_5 = 0.8`, `recall_at_0_5 = 1.0`, `false_positive_rate_at_0_5 = 0.125`.
  - `pooled_measured_and_decoys` (`4` actives vs `4` measured inactives + `8` untested decoys, `prevalence = 0.25`, `never_measured_negative_share = 0.6667`): `roc_auc = 0.8333`, `precision_at_0_5 = 0.5714`, `recall_at_0_5 = 1.0`, `false_positive_rate_at_0_5 = 0.25`.
